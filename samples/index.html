Before you launch

Samples need JavaScript, HTTPS (or localhost), and an available WebGPU adapter. Browser and device support varies; there is no WebGL or Canvas2D fallback.

Check this browser before opening a sample.

Experimental backend

Basic pointer, keyboard and wheel input are supported. IME composition, clipboard integration and an accessibility tree for canvas widgets are not yet available. The landing page itself uses ordinary accessible HTML.
